2. CẤU TRÚC THƯ MỤC BÀN GIAO
--------------------------------------------------------------------------------
- src/                     : Toàn bộ mã nguồn React (Components, Pages, Hooks, Styles, Data).
- dist/                    : Bản build Production tĩnh đã tối ưu sẵn sàng deploy ngay.
- scripts/                 : Các script tự động hóa (Audit BCT, Sinh catalog, Build GitHub Pages).
- worker/                  : Cloudflare Worker tích hợp đồng bộ dữ liệu S3 POS (fm.es3.vn).
- images/ & videos/        : Toàn bộ tài nguyên đa phương tiện độ phân giải cao của dự án.
- docs/ & tests/           : Tài liệu kỹ thuật kiến trúc hệ thống và test cases.
- Danh_Muc_54_San_Pham_SkinID_S3POS.xlsx : Bảng dữ liệu đối soát 54 SKU theo chuẩn S3 POS.
- Bao_Cao_Audit_SkinID_BCT_UXUI.md      : Báo cáo kiểm toán chuyên sâu thị giác và pháp lý BCT.
- package.json & package-lock.json      : Quản lý dependencies dự án (Node.js/Vite/React).
- vite.config.mjs          : Cấu hình build tối ưu đa nền tảng.
- .env & .dev.vars         : Cấu hình môi trường (Firebase, Gemini API, S3 POS credentials).

3. HƯỚNG DẪN CÀI ĐẶT & KHỞI CHẠY (DÀNH CHO ĐỘI NGŨ KỸ THUẬT)
--------------------------------------------------------------------------------
Bước 1: Cài đặt Node.js phiên bản LTS (khuyến nghị Node v20+ hoặc v22+).
Bước 2: Giải nén gói mã nguồn vào thư mục làm việc.
Bước 3: Mở terminal tại thư mục dự án và cài đặt dependencies:
        npm install
Bước 4: Chạy môi trường phát triển (Development):
        npm run dev
        -> Truy cập: http://localhost:5173
Bước 5: Đóng gói và build bản Production:
        npm run build
        -> Kết quả build nằm tại thư mục dist/ và sẵn sàng triển khai.
